# Recursion — Solving Problems by Self-Reference

## Mental

A **recursive** function solves a problem by calling itself on a
smaller instance, then combining results. It mirrors the structure
of inductive proof (Strand 8 Foundation Lesson 06):

- **Base case**: directly solve the smallest instance.
- **Recursive case**: reduce to a strictly smaller instance and
  combine.

Termination requires that **every recursive call descends toward the
base case**.

## Worked example: factorial

$$
n! = \begin{cases} 1 & n = 0 \\ n \cdot (n-1)! & n > 0 \end{cases}
$$

```python
def factorial(n):
    if n == 0: return 1
    return n * factorial(n - 1)
```

The call stack for `factorial(4)`: `4 * factorial(3)` →
`4 * (3 * factorial(2))` → ... → `4 * 3 * 2 * 1 * 1 = 24`. Each
call descends by 1; base case at $n = 0$.

## Worked example: Fibonacci

$$
F_n = F_{n-1} + F_{n-2}, \quad F_0 = 0, F_1 = 1.
$$

Naive recursion:

```python
def fib(n):
    if n < 2: return n
    return fib(n - 1) + fib(n - 2)
```

This is $O(\phi^n)$ — exponential, because subproblems are
recomputed. With **memoization** (cache results), it drops to
$O(n)$.

## Divide and conquer

Many fast algorithms are recursive:

- **Mergesort**: split list in half, sort each half recursively,
  merge — $O(n \log n)$.
- **Binary search**: compare middle, recurse into left or right
  half — $O(\log n)$.
- **Tree traversal**: visit a node, recurse on each subtree.

The pattern: **divide** the problem, **conquer** subproblems,
**combine** results.

## Symbolic

**Recursion theorem** (Strand 8 Lesson 03): if $f(0)$ and $f(S(n)) = g(f(n))$
are specified, $f$ is uniquely determined. Recursive definitions are
sound.

**Tail recursion**: when the recursive call is the last action of
the function. Compilers can transform tail recursion into a loop —
no extra stack frames. Python doesn't optimize this; Scheme and
Haskell do.

**Recursion depth limit**: each call consumes a stack frame. Default
Python limit is 1000. Deep recursion needs an iterative version or
explicit stack.

## Computational

```python
# Factorial — recursive
def factorial(n):
    return 1 if n == 0 else n * factorial(n - 1)

# Fibonacci — naive (slow)
def fib_slow(n):
    return n if n < 2 else fib_slow(n - 1) + fib_slow(n - 2)

# Fibonacci — memoized (fast)
from functools import lru_cache
@lru_cache(maxsize=None)
def fib_fast(n):
    return n if n < 2 else fib_fast(n - 1) + fib_fast(n - 2)

print(factorial(10))    # 3628800
print(fib_fast(50))     # 12586269025

# Mergesort
def merge(a, b):
    out, i, j = [], 0, 0
    while i < len(a) and j < len(b):
        if a[i] <= b[j]:
            out.append(a[i]); i += 1
        else:
            out.append(b[j]); j += 1
    return out + a[i:] + b[j:]

def mergesort(L):
    if len(L) <= 1: return L
    mid = len(L) // 2
    return merge(mergesort(L[:mid]), mergesort(L[mid:]))

print(mergesort([5, 2, 8, 1, 9, 3, 7, 4]))   # sorted
```

## Applied

- **Trees and graphs** — every tree algorithm is naturally recursive.
- **Parsers** — recursive descent parses programming languages by
  matching grammar productions recursively.
- **AI search** — minimax (game-tree search), depth-first search,
  backtracking are recursive.
- **Fractals** — Mandelbrot, Sierpinski triangle, Koch snowflake
  generated by recursion.
- **Divide and conquer in practice** — FFT, Strassen matrix multiply,
  closest-pair-in-plane.
