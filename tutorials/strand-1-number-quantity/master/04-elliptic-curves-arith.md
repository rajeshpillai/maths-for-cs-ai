# Arithmetic of Elliptic Curves

## Explain Like I Am 7

Imagine a smooth, looping racetrack where you can pick any two
checkpoints, draw the straight stick joining them, and bounce that
stick off the curve to land on a new "sum" checkpoint.  This bouncing
game turns a swooping curve into a pocket calculator: every
fraction-coordinate point becomes addable to every other.  Looking at
which checkpoints have nice fraction coordinates — and how they
combine — is one of the deepest puzzles in number theory, and it's
also what hides your phone's keys when you tap to pay.

## Mental

An **elliptic curve** over $\mathbb{Q}$ is a smooth Weierstrass curve

$$
E : y^2 = x^3 + a x + b, \quad a, b \in \mathbb{Q}.
$$

The **Mordell-Weil group** $E(\mathbb{Q})$ — rational points plus
$\mathcal O$ — is a *finitely generated abelian group*:

$$
E(\mathbb{Q}) \cong \mathbb{Z}^r \oplus T,
$$

with **rank** $r \ge 0$ and finite **torsion** $T$. The **Mordell
conjecture** (proven by Faltings 1983 for all higher-genus curves,
direct for genus 1) underlies this.

## Mazur's torsion theorem (1977)

The torsion subgroup $T$ of $E(\mathbb{Q})$ is one of **15 specific
groups**:

$\mathbb{Z}/n$ for $n \in \{1, \ldots, 10, 12\}$, or
$\mathbb{Z}/2 \times \mathbb{Z}/2n$ for $n \in \{1, 2, 3, 4\}$.

Severely constrained — and entirely classified.

## The rank

The **rank** $r$ is conjecturally bounded; the largest known rank
is 28 (Elkies). It's an open question whether $r$ can be arbitrarily
large.

For a "random" elliptic curve, the rank is expected to be 0 or 1
half the time each (Goldfeld-Katz-Sarnak heuristic).

## Worked example

$E : y^2 = x^3 - x$. $E(\mathbb{Q})$:

- Torsion: $\{(0, 0), (1, 0), (-1, 0), \mathcal O\} \cong (\mathbb{Z}/2)^2$.
- Rank 0 (proven via descent).

So $E(\mathbb{Q})$ is just these 4 points. Compare:

$E : y^2 = x^3 - 2$. Has rank 1, generator $(3, 5)$. Infinitely many
rational points generated by adding the generator to itself.

## Reduction modulo $p$

Reducing $E$ mod a prime $p$ (for $p$ not dividing the discriminant
$\Delta_E$) gives an elliptic curve over $\mathbb{F}_p$ with
$|E(\mathbb{F}_p)|$ points. Hasse's bound:

$$
|p + 1 - |E(\mathbb{F}_p)|| \le 2\sqrt p.
$$

The number $a_p = p + 1 - |E(\mathbb{F}_p)|$ — *Frobenius trace* —
fits in $|a_p| \le 2\sqrt p$. Schoof's algorithm computes $a_p$ in
polynomial time.

## Symbolic

**L-function of $E$**: encodes $a_p$ for all primes:

$$
L(s, E) = \prod_p (1 - a_p p^{-s} + p^{1 - 2s})^{-1}.
$$

Modularity (Lesson 03): $L(s, E)$ equals $L(s, f)$ for some weight-2
modular form $f$.

**Tate-Shafarevich group** $\Sha(E)$ — measures failure of local-
global principle. Conjecturally finite; proven finite in many
specific cases. RH-style mystery.

**Endomorphism ring**: typically $\mathbb{Z}$ (random curve), but
**CM curves** have endomorphism ring an order in an imaginary
quadratic field — special arithmetic.

## Computational

```python
import sympy as sp

# Use SymPy or PARI/GP wrapper. Here, manual EC arithmetic mod p.
P = 11                  # small prime
A = -1                  # curve y^2 = x^3 - x
B = 0

def is_on_curve(x, y, p=P, a=A, b=B):
    return (y*y - x*x*x - a*x - b) % p == 0

# Count points on E(F_p)
points = [(x, y) for x in range(P) for y in range(P) if is_on_curve(x, y)]
N = len(points) + 1     # +1 for point at infinity
print(f"|E(F_{P})| = {N}")
print(f"a_p = p + 1 - N = {P + 1 - N}")
print(f"Hasse bound: |a_p| <= 2 sqrt(p) = {2 * P**0.5:.2f}")

# Schoof-Atkin-Elkies (SEA) algorithm computes a_p in poly time
# For huge p (used in cryptographic curves), SEA is the method.

# Mordell-Weil rank computation requires sophisticated tools (PARI, SAGE)

# E.rank()              # 0
# E.torsion_subgroup()  # Z/2 x Z/2
```

## Applied

- **ECDSA / ECDH** — every elliptic-curve crypto scheme uses curves
  over $\mathbb{F}_p$ chosen for hardness of ECDLP.
- **Curve selection** — NIST, Curve25519, secp256k1 all chosen with
  Hasse-bound-aware analysis to ensure prime-order subgroups.
- **Pairing-based crypto** — pairings on special "pairing-friendly"
  elliptic curves (BLS12-381 in zk-SNARKs).
- **Isogeny-based crypto** — SIDH/SIKE used isogenies between
  supersingular curves; broken 2022, but variants (CSIDH) survive.
- **Schoof's algorithm** — point counting on EC over $\mathbb{F}_p$
  in polynomial time, foundational for crypto-curve generation.
