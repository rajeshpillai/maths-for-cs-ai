# Iwasawa Theory

## Explain Like I Am 7

Picture a magnificent watchtower being built one storey at a time, and
each new floor adds a tiny twist to the whole tower's shape.
Iwasawa's idea: instead of staring at one floor, watch how a single
fixed property (like "how broken is unique factorisation here?")
**evolves** as you climb.  Surprisingly, the way these properties
shift floor by floor is governed by a single, hidden $p$-adic
function — like a single tune that the whole tower hums.  That tune
is conjectured to *be* the $p$-adic L-function we met before.

## Mental

For a prime $p$, consider the **cyclotomic $\mathbb Z_p$-extension**

$$
\mathbb Q \subset \mathbb Q(\zeta_p) \subset \mathbb Q(\zeta_{p^2}) \subset \ldots \subset \mathbb Q_\infty.
$$

$\mathrm{Gal}(\mathbb Q_\infty / \mathbb Q) \cong \mathbb Z_p$.
**Iwasawa theory** studies how arithmetic invariants vary along this
tower.

## Iwasawa's main conjecture

For a number field $F$ with $\mathbb Z_p$-extension, Iwasawa
constructed a **module** $X_\infty$ encoding class-group data along
the tower.

**Main conjecture** (Mazur-Wiles 1984 for $\mathbb Q$, Wiles 1990 for
totally real fields, Skinner-Urban 2014 for elliptic curves):

The **characteristic ideal** of $X_\infty$ as a module over the
Iwasawa algebra $\Lambda = \mathbb Z_p[[T]]$ is generated by a
specific **$p$-adic L-function**.

This relates *algebraic* invariants (modules of class groups) to
*analytic* ones ($p$-adic L-values) — a $p$-adic analogue of class
number formulas.

## Iwasawa's $\mu, \lambda, \nu$ invariants

For the class number $h(F_n)$ at level $n$ in the tower:

$$
\mathrm{ord}_p h(F_n) = \mu p^n + \lambda n + \nu \quad \text{for } n \gg 0.
$$

$\mu, \lambda, \nu$ are arithmetic invariants of the tower.
$\mu$ conjecturally vanishes for many cyclotomic cases (Ferrero-
Washington 1979).

## Symbolic

**$p$-adic L-functions**: $p$-adic interpolations of complex
L-values. Key example: Kubota-Leopoldt $p$-adic zeta.

**Iwasawa algebra** $\Lambda = \mathbb Z_p[[\Gamma]] \cong \mathbb Z_p[[T]]$
where $\Gamma = \mathrm{Gal}(F_\infty / F)$.

**Selmer groups**: BSD-style invariants of elliptic curves; Iwasawa
theory studies their behaviour in towers.

**Greenberg's main conjecture**: extends to general motives /
Galois representations.

## Computational

# Iwasawa theory is heavily research-grade; sketch
# p-adic class numbers along a Z_p-extension

# For Q(zeta_5^n), class numbers known for small n:
# h(Q(zeta_5)) = 1, h(Q(zeta_25)) = 1, ...
# Vandiver's conjecture: p never divides h(Q(zeta_p)^+) — verified up to p < 2^31

# Iwasawa formula: ord_p(h(F_n)) = μ p^n + λ n + ν for n large
def iwasawa_pattern(n, mu=0, lam=0, nu=0):
    return mu * (10**n) + lam * n + nu

# For Q's cyclotomic Z_p extension at p = 5:
# Known empirically μ = 0, λ = 0, ν = 0 (very small class growth)
print([iwasawa_pattern(n, 0, 0, 0) for n in range(5)])  # all 0

## Applied

- **Modular forms** — Iwasawa theory of modular Galois representations
  is the engine of modern arithmetic.
- **BSD conjecture** — Iwasawa theory proves cases of BSD for elliptic
  curves of analytic rank 1.
- **Class field theory** — tower-based methods underlie modern
  algorithms.
- **Crypto** — Iwasawa-style estimates inform security parameters of
  isogeny-based and lattice-based crypto.
