# Galois Groups

## Mental

For a Galois extension $K/F$, the **Galois group**
$\mathrm{Gal}(K/F)$ is the set of all field automorphisms of $K$
that fix $F$ pointwise:

$$
\mathrm{Gal}(K/F) = \{\sigma : K \to K \mid \sigma \text{ is a field auto, } \sigma|_F = \mathrm{id}\}.
$$

Group operation: composition. Identity: identity map.

The Galois group encodes the *symmetry of the roots* of the polynomial
defining $K$.

## Worked example: $\mathrm{Gal}(\mathbb{Q}(\sqrt 2)/\mathbb{Q})$

$K = \mathbb{Q}(\sqrt 2) = \{a + b\sqrt 2 : a, b \in \mathbb{Q}\}$.

Any automorphism $\sigma$ must fix $\mathbb{Q}$, so it's determined by
$\sigma(\sqrt 2)$. The minimal polynomial of $\sqrt 2$ is $x^2 - 2$,
so $\sigma(\sqrt 2)$ must also be a root: $\sqrt 2$ or $-\sqrt 2$.

Two automorphisms: identity, and $\sqrt 2 \mapsto -\sqrt 2$. So
$\mathrm{Gal}(\mathbb{Q}(\sqrt 2)/\mathbb{Q}) \cong \mathbb{Z}/2$.

## Worked example: $\mathrm{Gal}(\mathbb{Q}(\sqrt[3]{2}, \omega)/\mathbb{Q})$

The full splitting field of $x^3 - 2$. The Galois group has order 6
(matching the degree).

$\sigma$ permutes the three roots $\sqrt[3]{2}, \omega \sqrt[3]{2}, \omega^2 \sqrt[3]{2}$
of $x^3 - 2$. Every permutation of the three is achievable:

$$
\mathrm{Gal} \cong S_3.
$$

## Why $|G| = [K : F]$ for Galois extensions

Each automorphism is determined by its image on a basis. The
constraints — "fix $F$, send roots to roots" — leave exactly
$[K:F]$ choices.

This is **the** characterisation: $K/F$ is Galois iff
$|\mathrm{Aut}(K/F)| = [K:F]$.

## Symbolic

**Galois group of finite fields**: $\mathrm{Gal}(\mathbb{F}_{p^n}/\mathbb{F}_p)$
is **cyclic of order $n$**, generated by the **Frobenius automorphism**
$\phi : x \mapsto x^p$.

**Galois group of cyclotomic fields**:
$\mathrm{Gal}(\mathbb{Q}(\zeta_n)/\mathbb{Q}) \cong (\mathbb{Z}/n)^*$
— the multiplicative group modulo $n$. Particularly clean and
Abelian.

**Galois group as permutation group**: any Galois group acts
faithfully on the roots of the defining polynomial. The image is a
**transitive** subgroup of $S_n$ where $n$ is the number of roots.

## Computational

```python
import sympy as sp

x = sp.symbols("x")

# Galois group of x^3 - 2: S_3
print(sp.solve(x**3 - 2, x))         # three roots

# Galois group of x^4 - 5x^2 + 6 = (x^2 - 2)(x^2 - 3)
# splitting field Q(sqrt 2, sqrt 3), Galois group V_4
print(sp.factor(x**4 - 5*x**2 + 6))   # (x²-2)(x²-3)

# Cyclotomic Galois group: Gal(Q(zeta_n)/Q) ≅ (Z/n)*
def cyclotomic_galois_order(n):
    return sp.totient(n)

print(cyclotomic_galois_order(8))     # 4 — phi(8) = 4
print(cyclotomic_galois_order(12))    # 4 — phi(12) = 4

# Demonstrate Frobenius in F_4
def frobenius_F4(coeffs):
    # F_4 = F_2[x]/(x^2 + x + 1); element a + b*alpha
    a, b = coeffs
    # phi(a + b alpha) = a^2 + b^2 alpha^2 = a + b(alpha + 1) (in F_2)
    return (a + b, b)

print(frobenius_F4((0, 1)))     # (1, 1) — sends alpha to alpha + 1
```

## Applied

- **Inverse Galois problem** — given a finite group $G$, is there a
  Galois extension of $\mathbb{Q}$ with Galois group $G$? Open in
  full generality but solved for many classes.
- **Number theory** — much of class-field theory, Iwasawa theory,
  automorphic forms is Galois-theoretic.
- **Cryptography** — Galois groups of cyclotomic fields underlie
  the security of Ring-LWE.
- **Polynomial factorisation algorithms** (Trager-Buchberger) use
  Galois-theoretic insights for primitive elements.
