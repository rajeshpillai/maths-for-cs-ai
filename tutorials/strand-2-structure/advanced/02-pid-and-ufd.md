# PIDs and UFDs

## Mental

A **principal ideal domain (PID)** is an integral domain in which
every ideal is principal — generated by a single element.

A **unique factorisation domain (UFD)** is an integral domain in
which every nonzero non-unit factors uniquely (up to order and units)
into irreducibles.

Hierarchy:

$$
\text{Field} \subset \text{Euclidean domain} \subset \text{PID} \subset \text{UFD} \subset \text{Integral domain}.
$$

Every Euclidean domain is a PID; every PID is a UFD. The reverse
implications fail in general.

## Examples

- $\mathbb{Z}$ — Euclidean (use $|n|$), PID, UFD.
- $\mathbb{Z}[i]$ — Gaussian integers, Euclidean (use $|a + bi|^2$),
  PID, UFD.
- $F[x]$ for a field $F$ — Euclidean (degree), PID, UFD.
- $\mathbb{Z}[x]$ — UFD but **not** PID. $(2, x)$ is non-principal.
- $\mathbb{Z}[\sqrt{-5}]$ — integral domain but **not** UFD:
  $6 = 2 \cdot 3 = (1 + \sqrt{-5})(1 - \sqrt{-5})$, two genuinely
  different factorisations.

## Why these matter

**PID**: every ideal is captured by one generator — like saying "every
sub-collection of integers under arithmetic is just multiples of one
number." This makes algorithms (gcd, factoring, solving linear
Diophantine equations) tractable.

**UFD**: factorisation is essentially unique, so notions like "common
factor" make sense. Without UFD, even "prime" splits into "irreducible"
(can't factor) vs "prime" ($p \mid ab \Rightarrow p \mid a$ or $p \mid b$),
and these differ.

## Worked example: failure of UFD in $\mathbb{Z}[\sqrt{-5}]$

$6 = 2 \cdot 3$. Also $6 = (1 + \sqrt{-5})(1 - \sqrt{-5})$.

Each factor is irreducible: $|2|^2 = 4$, $|3|^2 = 9$, and
$|1 \pm \sqrt{-5}|^2 = 6$. No element of $\mathbb{Z}[\sqrt{-5}]$ has
norm $2$ or $3$, so these can't be split further.

**But**: $2$ and $1 + \sqrt{-5}$ are not associates, so the two
factorisations are genuinely distinct. UFD fails.

The fix (Dedekind): replace elements with **ideals**. The ring
$\mathbb{Z}[\sqrt{-5}]$ has unique factorisation of *ideals* into
prime ideals — Dedekind domains.

## Symbolic

**Bezout's identity** (in a PID): for any $a, b$, there exist $r, s$
with $\gcd(a, b) = ra + sb$.

**Euclidean algorithm**: in a Euclidean domain, gcd is computed by
repeated remainder. The classical $\mathbb{Z}$ algorithm extends to
$F[x]$, $\mathbb{Z}[i]$, etc.

**Noetherian** ring: every ascending chain of ideals stabilises,
equivalently every ideal is finitely generated. PIDs are Noetherian
(trivially). $\mathbb{Z}[x_1, x_2, \ldots]$ — countably many variables
— is *not* Noetherian.

## Computational

```python
import sympy as sp

x = sp.symbols("x")

# Euclidean algorithm in Z and Z[x]
print(sp.gcd(60, 84))                          # 12 — Z
print(sp.gcd(x**2 - 1, x**2 + 3*x + 2))        # x + 1 — Z[x]

# Bezout's identity
def extended_gcd(a, b):
    if b == 0: return a, 1, 0
    g, x, y = extended_gcd(b, a % b)
    return g, y, x - (a // b) * y

g, r, s = extended_gcd(60, 84)
print(g, r, s, 60*r + 84*s)                    # 12, ..., ..., 12

# Factorisation in Z[i] (Gaussian integers)
# Norm of a + b*i = a^2 + b^2
def gauss_norm(a, b): return a*a + b*b

# 5 = (2 + i)(2 - i): both have norm 5 (prime), so irreducible
print(gauss_norm(2, 1), gauss_norm(2, -1))     # 5 5

# Demonstrate non-UFD in Z[sqrt(-5)]
# 6 = 2 * 3 = (1 + sqrt(-5))(1 - sqrt(-5))
# Norms: 4, 9, 6, 6 — all elements irreducible (none of norm 2, 3)
```

## Applied

- **Computer algebra systems** — Mathematica, Maple, SymPy implement
  factorisation algorithms that exploit UFD structure (Berlekamp,
  Zassenhaus, Cantor-Zassenhaus over finite fields).
- **Public-key cryptography** — RSA's security rests on integer
  factorisation being hard *despite* unique factorisation existing.
- **Number-theoretic transforms** — work in $\mathbb{Z}[\zeta_n]$, a
  cyclotomic ring; factorisation matters for choice of parameters.
- **Coding theory** — factoring polynomials over $\mathbb{F}_q$ to
  find generator polynomials of cyclic codes.
