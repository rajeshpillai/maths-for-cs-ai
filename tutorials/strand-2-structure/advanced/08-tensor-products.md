# Tensor Products

## Explain Like I Am 7

Imagine two grids of pegs — one of three pegs and one of four — sitting
side by side.  How do you "multiply" them into a single bigger object?
The **tensor product** invents a brand-new $3 \times 4$ peg-grid where
every pair of an old peg from grid A and an old peg from grid B has its
own fresh peg.  Combining two stretchable arrow-collections this way
makes a *bigger* stretchable collection, and it's the engine behind
modern AI's multi-dimensional arrays — every neural network's hidden
state is, deep down, a tensor product.

## Mental

Given $R$-modules $M$ and $N$, the **tensor product** $M \otimes_R N$ is
an $R$-module designed to **linearise bilinear maps**: every bilinear
map $M \times N \to P$ factors uniquely as $M \times N \to M \otimes N \to P$
where the second arrow is linear.

So tensor products are the universal way to "multiply" modules.

## Construction

$M \otimes_R N$ is generated by symbols $m \otimes n$ subject to:

- $(m_1 + m_2) \otimes n = m_1 \otimes n + m_2 \otimes n$.
- $m \otimes (n_1 + n_2) = m \otimes n_1 + m \otimes n_2$.
- $(rm) \otimes n = m \otimes (rn) = r(m \otimes n)$.

Elements are *finite sums* $\sum m_i \otimes n_i$.

## Key facts

For free modules: $R^a \otimes R^b \cong R^{ab}$. So tensor product of
finite-dim vector spaces multiplies dimensions.

**Examples**:

- $\mathbb{R}^2 \otimes \mathbb{R}^3 \cong \mathbb{R}^6$.
- $\mathbb{Z}/2 \otimes_\mathbb{Z} \mathbb{Z}/3 = 0$ (because in
  $a \otimes b$, multiplying both sides by $\gcd^{-1}$ kills it).
- $\mathbb{Q} \otimes_\mathbb{Z} M = $ "rationalize" $M$ — kill
  torsion and make divisions valid.

## Worked example: $\mathbb{R}^2 \otimes \mathbb{R}^3$

Basis: $\{e_1 \otimes f_1, e_1 \otimes f_2, e_1 \otimes f_3, e_2 \otimes f_1, e_2 \otimes f_2, e_2 \otimes f_3\}$.

Six elements. A general tensor: $\sum_{ij} a_{ij} (e_i \otimes f_j)$,
which we can record as a $2 \times 3$ matrix.

But a *general* element of $\mathbb{R}^2 \otimes \mathbb{R}^3$ is not
$\mathbf{u} \otimes \mathbf{v}$ for some vectors $\mathbf{u}, \mathbf{v}$
— such "rank-1" tensors form a 4-dimensional subset of the 6-dim
total.

## Symbolic

**Tensors and multilinear maps**: a tensor $T \in V_1 \otimes \ldots \otimes V_k$
corresponds to a multilinear function $V_1^* \times \ldots \times V_k^* \to F$.

**Tensor rank**: minimum number of pure tensors needed to express a
given tensor. For matrices (= 2-tensors), rank coincides with usual
matrix rank. For higher-order tensors, rank is much harder
(NP-hard in general!).

**Tensor decomposition**: PARAFAC/CANDECOMP, Tucker decomposition,
hierarchical Tucker, tensor train (TT). Used in quantum information,
recommendation systems, neural-network compression.

**Tensor categories**: Hilbert-space tensor product is the basis of
quantum entanglement: $\psi_{AB} \in \mathcal{H}_A \otimes \mathcal{H}_B$
need not be $\psi_A \otimes \psi_B$.

## Computational

```python
import numpy as np

# Tensor product of vectors (outer product)
u = np.array([1, 2])
v = np.array([3, 4, 5])
print(np.outer(u, v))                # 2x3, rank 1

# General tensor in R^2 ⊗ R^3 — a 2x3 matrix not necessarily rank 1
T = np.array([[1, 2, 3], [4, 5, 6]])
print(np.linalg.matrix_rank(T))      # 2 — not rank 1, so not a pure tensor

# Higher-order tensor: einsum is the indexed-tensor calculus
A = np.random.randn(2, 3)
B = np.random.randn(3, 4)
print(np.einsum("ij,jk->ik", A, B).shape)  # (2, 4) — matrix product
print(np.einsum("ij,kl->ijkl", A, B).shape)  # (2, 3, 3, 4) — outer/tensor product

# Quantum entanglement example: Bell state
# |00> + |11>, in C^2 ⊗ C^2 — not a product state!
bell = np.array([[1, 0], [0, 1]]) / np.sqrt(2)
print(np.linalg.matrix_rank(bell))   # 2 — entangled
```

## Applied

- **Transformer attention** — $QK^T$ is an outer product; multi-head
  attention concatenates several. Tensor structure underlies
  efficient implementations.
- **Recommendation systems** — user × item × time tensors decomposed
  via PARAFAC/Tucker.
- **Quantum computing** — n-qubit states live in
  $(\mathbb{C}^2)^{\otimes n}$, dimension $2^n$. Entangled states
  resist factoring as a tensor product.
- **Tensor networks** for compressing high-dim distributions:
  matrix product states, PEPS, MERA in physics.
- **Differential geometry** — tensor fields (metric, curvature) on
  manifolds.
