# Symmetry Groups — Cyclic and Dihedral

## Mental

A **symmetry** of a shape is a transformation (rotation, reflection)
that maps the shape to itself.

For an equilateral triangle:

- $3$ rotations: $0°, 120°, 240°$.
- $3$ reflections: across each axis through a vertex.
- Total: $6$ symmetries.

These $6$ symmetries form a group under composition — the **dihedral
group** $D_3$.

For a regular $n$-gon:

- $n$ rotations.
- $n$ reflections.
- Total: $2n$ symmetries.

This is the **dihedral group** $D_n$ of order $2n$.

## Cyclic groups

A **cyclic group** $\mathbb{Z}/n\mathbb{Z}$ (under addition) has $n$
elements, generated by a single element. The rotational symmetries
of a regular $n$-gon (without reflections) form the cyclic group
$C_n$ of order $n$.

$C_n$ and $D_n$ have a containment: $C_n \subset D_n$. The cyclic
subgroup is the rotations only.

## Concrete: $D_3$ table

Label rotations $r_0, r_1, r_2$ ($0°, 120°, 240°$) and reflections
$s_0, s_1, s_2$. The composition table is $6 \times 6$.

A simpler way to think: every element of $D_n$ is either $r^k$ for
some $k$ or $s r^k$. Composition rules:

- $r^k \cdot r^j = r^{k+j \mod n}$.
- $s \cdot s = e$.
- $s \cdot r = r^{-1} \cdot s$ (reflection-rotation order swap).

These three rules generate the full group.

## Symbolic

The **cyclic group** $C_n$ has presentation $\langle r : r^n = e \rangle$
— one generator $r$ of order $n$.

The **dihedral group** $D_n$ has presentation $\langle r, s : r^n =
s^2 = e, srs = r^{-1} \rangle$.

**Klein four-group** $V_4 = D_2$: special case with 4 elements, all
of order 2 (except identity). Symmetries of a non-square rectangle.
Abelian.

**Dihedral relations**: $D_n$ is non-abelian for $n \ge 3$.

## Computational

```python
import numpy as np

def rotation_matrix(theta_deg):
    theta = np.radians(theta_deg)
    return np.array([[np.cos(theta), -np.sin(theta)],
                     [np.sin(theta),  np.cos(theta)]])

def reflection_x():
    return np.array([[1, 0], [0, -1]])

# D_3 generators
n = 3
r = rotation_matrix(360 / n)
s = reflection_x()

# Verify rs = r^{-1} s? In D_n, srs = r^{-1}.
print(np.allclose(s @ r @ s, np.linalg.inv(r)))   # True

# Generate all 2n elements of D_n
elements = []
for i in range(n):
    elements.append(np.linalg.matrix_power(r, i))
    elements.append(s @ np.linalg.matrix_power(r, i))
print(f"Elements of D_{n}: {len(elements)}")   # 2n
```

## Applied

- **Crystallography**: 230 space groups in 3D classify all crystal
  symmetries.
- **Music theory**: cyclic group $\mathbb{Z}/12\mathbb{Z}$ underlies
  octave equivalence; dihedral structure underlies mode/inversion
  symmetries.
- **Coding theory**: cyclic codes (Reed-Solomon, BCH) are based on
  cyclic groups.
