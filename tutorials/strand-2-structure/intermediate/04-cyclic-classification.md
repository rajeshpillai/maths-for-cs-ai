# Cyclic Group Classification

## Mental

A group $G$ is **cyclic** if there's some $g \in G$ — a *generator*
— such that every element is a power of $g$:

$$
G = \langle g \rangle = \{\ldots, g^{-2}, g^{-1}, e, g, g^2, \ldots\}.
$$

**Classification** (a strong result):

- Every **infinite cyclic group** is isomorphic to $(\mathbb{Z}, +)$.
- Every **finite cyclic group of order $n$** is isomorphic to
  $(\mathbb{Z}/n\mathbb{Z}, +)$.

So *up to isomorphism*, there's exactly **one cyclic group of each
size** (plus the unique infinite one). The full classification of
cyclic groups is just $\{\mathbb{Z}, \mathbb{Z}/2, \mathbb{Z}/3, \mathbb{Z}/4, \ldots\}$.

## Generators

How many generators does $\mathbb{Z}/n$ have? An element $k$
generates iff $\gcd(k, n) = 1$. The count is **Euler's totient**
$\phi(n)$.

| $n$ | Generators of $\mathbb{Z}/n$ | $\phi(n)$ |
|---|---|---|
| 6 | 1, 5 | 2 |
| 8 | 1, 3, 5, 7 | 4 |
| 12 | 1, 5, 7, 11 | 4 |
| $p$ prime | $1, 2, \ldots, p-1$ | $p-1$ |

## Subgroups of $\mathbb{Z}/n$

**Theorem**: subgroups of $\mathbb{Z}/n$ correspond to **divisors of $n$**.
For each $d \mid n$, there's a unique subgroup of order $d$,
generated by $n/d \pmod n$.

For $n = 12$, divisors are $\{1, 2, 3, 4, 6, 12\}$ — six subgroups.

## Worked example: subgroups of $\mathbb{Z}/12$

| $d$ | Subgroup | Generator |
|---|---|---|
| 1 | $\{0\}$ | — |
| 2 | $\{0, 6\}$ | $6$ |
| 3 | $\{0, 4, 8\}$ | $4$ |
| 4 | $\{0, 3, 6, 9\}$ | $3$ |
| 6 | $\{0, 2, 4, 6, 8, 10\}$ | $2$ |
| 12 | $\mathbb{Z}/12$ | $1$ |

The lattice mirrors the **divisibility lattice** of 12.

## Symbolic

**Generators of $\mathbb{Z}/n$**: $k$ is a generator iff $\gcd(k, n) = 1$,
giving $\phi(n)$ generators.

**Subgroup of order $d$ in $\mathbb{Z}/n$** (for $d \mid n$):

$$
\langle n/d \rangle = \{0, n/d, 2 n/d, \ldots, (d-1) n/d\}.
$$

**Cyclic subgroup of any group**: for any $g \in G$, $\langle g \rangle$
is a cyclic subgroup of order $|g|$. So every group contains plenty
of cyclic subgroups; the question is whether the **whole group** is
cyclic.

**Direct product caveat**: $\mathbb{Z}/m \times \mathbb{Z}/n$ is cyclic
iff $\gcd(m, n) = 1$, in which case it's $\cong \mathbb{Z}/(mn)$ (the
**Chinese remainder theorem**).

So $\mathbb{Z}/2 \times \mathbb{Z}/3 \cong \mathbb{Z}/6$ but
$\mathbb{Z}/2 \times \mathbb{Z}/2 \not\cong \mathbb{Z}/4$.

## Computational

```python
from math import gcd

def generators_of_Zn(n):
    return [k for k in range(1, n) if gcd(k, n) == 1]

def subgroups_of_Zn(n):
    return [tuple((i * n // d) % n for i in range(d))
            for d in sorted(set(d for d in range(1, n + 1) if n % d == 0))]

print(generators_of_Zn(12))     # [1, 5, 7, 11]
print(generators_of_Zn(7))      # [1, 2, 3, 4, 5, 6]

for sub in subgroups_of_Zn(12):
    print(sorted(sub))
# (0,) ... (0, 6) ... (0, 4, 8) ... etc.

# Verify CRT direct product
def Z_m_times_Z_n_orders(m, n):
    return sorted(((i, j), max(
        k for k in range(1, m * n + 1)
        if (k * i) % m == 0 and (k * j) % n == 0
    )) for i in range(m) for j in range(n))

# (Z/2 x Z/3) is cyclic — has element of order 6
# (Z/2 x Z/2) is not — every element has order ≤ 2
```

## Applied

- **Number-theoretic transforms (NTT)** — fast multiplication of
  large polynomials uses primitive roots of cyclic subgroups of
  $(\mathbb{Z}/p)^*$. Underlies post-quantum lattice crypto and
  signal processing on integers.
- **Diffie-Hellman** key exchange operates in a cyclic subgroup of
  $(\mathbb{Z}/p)^*$ generated by a chosen $g$.
- **CRT decomposition** — Chinese remainder theorem splits
  arithmetic mod $n = pq$ into faster arithmetic mod $p$ and mod
  $q$ in parallel.
- **Symmetric encryption** key schedules use cyclic group rotations
  via shift registers.
