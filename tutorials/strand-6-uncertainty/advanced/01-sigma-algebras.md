# $\sigma$-Algebras and Measurable Sets

## Mental

A **$\sigma$-algebra** $\mathcal F$ on a set $X$ is a collection of
subsets satisfying:

1. $X \in \mathcal F$.
2. Closed under complements: $A \in \mathcal F \Rightarrow X \setminus A \in \mathcal F$.
3. Closed under countable unions: $A_i \in \mathcal F \Rightarrow \bigcup A_i \in \mathcal F$.

Closure under countable union + complement gives closure under
countable intersection too.

Elements of $\mathcal F$ are the **measurable sets** — the only ones
the measure $\mu$ talks about.

## Important examples

- **Trivial**: $\{\emptyset, X\}$ — the smallest $\sigma$-algebra.
- **Power set** $2^X$ — all subsets; the largest.
- **Borel $\sigma$-algebra** $\mathcal{B}(\mathbb{R})$ — generated
  by open intervals; contains all "natural" subsets.
- **Lebesgue $\sigma$-algebra** $\mathcal{L}(\mathbb{R})$ —
  contains Borel + sets of measure zero (slight enlargement).

For probability: a **probability space** is $(\Omega, \mathcal F, P)$
where $\mathcal F$ is a $\sigma$-algebra of "events" and $P$ a
probability measure on it.

## Generating a $\sigma$-algebra

Given any collection $\mathcal C$ of subsets, $\sigma(\mathcal C)$
is the *smallest* $\sigma$-algebra containing $\mathcal C$.

Examples:

- $\sigma(\{\text{open intervals}\})$ in $\mathbb{R}$ = Borel
  $\sigma$-algebra.
- $\sigma(\{\text{half-open rectangles}\})$ in $\mathbb{R}^n$ =
  Borel.
- $\sigma$-algebra generated by a *random variable* $X$ — the
  smallest where $X$ is measurable. Used in conditioning.

## Worked example: Borel $\sigma$-algebra

The Borel sets include:

- All open sets and closed sets.
- All countable intersections of open sets ($G_\delta$ sets).
- All countable unions of closed sets ($F_\sigma$ sets).
- Combinations and so on, transfinitely.

Cardinality: $|\mathcal{B}(\mathbb{R})| = 2^{\aleph_0}$ (continuum) —
not all subsets, but plenty.

## Symbolic

**Measurable function**: $f : X \to Y$ is measurable if
$f^{-1}(\mathcal F_Y) \subseteq \mathcal F_X$ — preimages of
measurable sets are measurable.

In probability: a **random variable** is a measurable function
$X : \Omega \to \mathbb{R}$.

**Filtration** $\{\mathcal F_t\}_t$ — increasing sequence of
$\sigma$-algebras representing "information available at time $t$."
Used in stochastic processes; martingales adapt to filtrations.

**Conditional expectation** $\mathbb{E}[X | \mathcal G]$ — the
$\mathcal G$-measurable function "best approximating" $X$. The
proper definition needs Radon-Nikodym.

## Computational

```python
# Sigma-algebra generated by a partition
def sigma_algebra_from_partition(partition):
    # All subsets that are unions of partition blocks
    n = len(partition)
    sigma = []
    for mask in range(2**n):
        union = set()
        for i in range(n):
            if mask & (1 << i):
                union.update(partition[i])
        sigma.append(frozenset(union))
    return sigma

# Coin flip: outcomes {H, T}, sigma = {empty, {H}, {T}, {H, T}}
sigma = sigma_algebra_from_partition([{"H"}, {"T"}])
print(len(sigma))                 # 4

# Two coin flips: 4 outcomes -> 2^4 = 16 events
sigma = sigma_algebra_from_partition([
    {"HH"}, {"HT"}, {"TH"}, {"TT"}
])
print(len(sigma))                 # 16
```

## Applied

- **Stochastic processes** — filtrations capture "information
  flow"; martingales / Brownian motion live on filtered probability
  spaces.
- **Probabilistic programming** — semantics of probabilistic programs
  use $\sigma$-algebras to handle continuous distributions and
  conditionals correctly.
- **Statistical decision theory** — measurability conditions
  formalise "what can a decision rule depend on?"
- **Mathematical finance** — option-pricing models use filtrations
  to model the market's information.
