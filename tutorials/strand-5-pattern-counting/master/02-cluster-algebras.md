# Cluster Algebras

## Mental

A **cluster algebra** (Fomin-Zelevinsky 2002) is generated by a
distinguished family of generators (**cluster variables**) related
by **mutation** rules.

Start with a **seed** $(\mathbf x, B)$:
- $\mathbf x = (x_1, \ldots, x_n)$ — initial cluster.
- $B$ — exchange matrix (skew-symmetrizable integer matrix).

Mutation in direction $k$ replaces $x_k$ with new $x_k'$:

$$
x_k x_k' = \prod_{b_{ki} > 0} x_i^{b_{ki}} + \prod_{b_{ki} < 0} x_i^{-b_{ki}}.
$$

Iterating mutations generates an **infinite or finite** family of
cluster variables.

## Laurent phenomenon

**Theorem** (Fomin-Zelevinsky): every cluster variable, as a
function of the initial cluster $\mathbf x$, is a **Laurent
polynomial** in $x_1, \ldots, x_n$ — i.e., of the form $\frac{P}{x^a}$
for polynomial $P$ and monomial $x^a$.

This is *highly non-trivial*: rational expressions could a priori
have arbitrary denominators, but they're all monomial.

## Worked example: $A_2$ cluster algebra

$B = \begin{pmatrix} 0 & 1 \\ -1 & 0 \end{pmatrix}$.

Start with $\mathbf x = (x_1, x_2)$.

Mutate at 1: $x_1' = (x_2 + 1)/x_1$.
Mutate at 2 from new cluster: $x_2'' = (x_1' + 1)/x_2 = (x_2 + 1 + x_1)/(x_1 x_2)$.

Continue: 5 distinct cluster variables total in $A_2$:

$$
x_1, x_2, \frac{1 + x_2}{x_1}, \frac{1 + x_1 + x_2}{x_1 x_2}, \frac{1 + x_1}{x_2}.
$$

Each *is* Laurent in original $x_1, x_2$. The pattern returns to the
start after 5 mutations — **periodic**.

## Classification

**Finite-type** cluster algebras (finitely many cluster variables)
are classified by **Dynkin diagrams** $A_n, B_n, C_n, D_n, E_6, E_7, E_8$ —
the same classification as simple Lie algebras (Strand 3 Master
Lesson 04).

A profound and unexpected match.

## Symbolic

**Quiver mutations**: equivalent reformulation via directed graphs
$Q$. Mutation flips arrows incident to vertex $k$ and adds composite
arrows. Used heavily in **quiver representation theory**.

**Positivity conjecture** (proven by Lee-Schiffler, Gross-Hacking-
Keel-Kontsevich): coefficients in Laurent expansion are non-negative.

**Cluster categories** (Buan-Marsh-Reiten): triangulated categories
encoding cluster algebras.

**Connections to Teichmüller theory**: cluster algebras describe
discrete dynamics on moduli of decorated Riemann surfaces.

## Computational

```python
from sympy import symbols, simplify, Rational

x1, x2 = symbols("x1 x2")

# A_2 cluster algebra mutations
def mutate_A2(cluster, direction):
    if direction == 1:
        x1_new = (cluster[1] + 1) / cluster[0]
        return (simplify(x1_new), cluster[1])
    else:
        x2_new = (cluster[0] + 1) / cluster[1]
        return (cluster[0], simplify(x2_new))

cluster = (x1, x2)
seen = {cluster}
print("Initial:", cluster)
for step in range(8):
    direction = (step % 2) + 1
    cluster = mutate_A2(cluster, direction)
    print(f"After mutate {direction}:", cluster)
    if cluster in seen:
        print("  (back to seen — period detected)")
    seen.add(cluster)

# Verify Laurent property: each variable is a Laurent polynomial in (x1, x2)
# All denominators are monomials in x1, x2 — verifiable by inspection
```

## Applied

- **Quiver representation theory** — cluster algebras encode
  exchange relations among indecomposable representations.
- **String theory** — BPS states on certain Calabi-Yau geometries
  correspond to cluster variables.
- **Teichmüller theory** — coordinates on moduli of decorated
  surfaces are cluster variables; mutations correspond to flips of
  triangulations.
- **Total positivity** — cluster algebras emerged from studying
  totally positive matrices; Lusztig's canonical bases.
- **Combinatorial physics** — quantum integrable models feature
  cluster-algebraic structure.
