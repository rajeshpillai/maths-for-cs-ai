# Symmetric Functions

## Explain Like I Am 7

Imagine a polynomial in many letters $x_1, x_2, x_3, \ldots$ that
*doesn't care* if you swap any two letters around — like a salad
recipe where it doesn't matter which apple goes in which bowl.
These swap-proof polynomials live in their own special world with a
handful of natural building-blocks: sums of all $x_i$, sums of
products of pairs, sums of cubes, and so on.  Each of these is a
"basis" — a different way to spell the same swap-proof world.
They're the secret language behind characters and group symmetry.

## Mental

The **ring of symmetric functions** $\Lambda = \mathbb Z[x_1, x_2, \ldots]^S$
— polynomials invariant under all permutations of variables.

Five classical bases (all indexed by partitions):

| Basis | Notation | Description |
|---|---|---|
| Monomial | $m_\lambda$ | sum of $x^\alpha$ over orbit of $\lambda$ |
| Power sum | $p_n = x_1^n + x_2^n + \ldots$, $p_\lambda = \prod p_{\lambda_i}$ | $p_\lambda$ |
| Elementary | $e_n = \sum_{i_1 < \ldots < i_n} x_{i_1} \cdots x_{i_n}$ | $e_\lambda$ |
| Complete homogeneous | $h_n = \sum_{i_1 \le \ldots \le i_n} x_{i_1} \cdots x_{i_n}$ | $h_\lambda$ |
| Schur | $s_\lambda$ | from semistandard Young tableaux |

All freely generated by their indices. Schur basis is the
"natural" basis for representation theory.

## Newton's identities

Connect $p_n$ and $e_n$:

$$
n e_n = \sum_{i=1}^n (-1)^{i-1} e_{n-i} p_i.
$$

Allows converting between bases.

For example, in characteristic-0:

$p_1 = e_1$, $p_2 = e_1^2 - 2 e_2$, $p_3 = e_1^3 - 3 e_1 e_2 + 3 e_3$, ...

## Hopf algebra structure

$\Lambda$ is a **Hopf algebra**: has multiplication, comultiplication
($f \mapsto f(x_1, x_2, \ldots, y_1, y_2, \ldots)$ split into
$f \otimes g$), unit, counit, antipode satisfying compatibility.

Foundation of much of *combinatorial Hopf algebra theory*.

## Characters of $S_n$ via $\Lambda$

The **Frobenius characteristic** map sends a class function $\chi$ on
$S_n$ to a degree-$n$ symmetric function. Irreducible characters
$\chi^\lambda$ map to **Schur functions** $s_\lambda$.

Multiplication of Schurs ↔ tensor product of $S_n$ representations
(sort of, via induction). Algorithmic combinatorics' bread and
butter.

## Symbolic

**Cauchy identity**: $\sum_\lambda s_\lambda(x) s_\lambda(y) = \prod_{i, j} \frac{1}{1 - x_i y_j}$.

**Pieri rule**: $s_\lambda \cdot h_k = \sum_\mu s_\mu$ where $\mu$
ranges over partitions obtained from $\lambda$ by adding a horizontal
strip of size $k$.

**Macdonald polynomials**: 2-parameter $(q, t)$-deformation of Schur,
specialising to Hall-Littlewood, Jack, etc. Foundation of modern
algebraic combinatorics.

**Quasisymmetric functions** $\mathrm{QSym}$ — generalisation; Hopf
algebra dual to non-commutative symmetric functions.

## Computational

```python
import sympy as sp

x = sp.symbols("x1 x2 x3 x4")

# Power sums
p1 = sum(xi for xi in x)
p2 = sum(xi**2 for xi in x)
p3 = sum(xi**3 for xi in x)

# Elementary symmetric
e1 = p1
e2 = sum(x[i] * x[j] for i in range(4) for j in range(i+1, 4))
e3 = sum(x[i] * x[j] * x[k] for i in range(4) for j in range(i+1, 4) for k in range(j+1, 4))

# Newton's identity: p2 = e1² - 2 e2
print(sp.simplify(p2 - (e1**2 - 2*e2)))   # 0

# p3 = e1³ - 3 e1 e2 + 3 e3
print(sp.simplify(p3 - (e1**3 - 3*e1*e2 + 3*e3)))   # 0

# Complete homogeneous
h1 = e1
h2 = sum(x[i] * x[j] for i in range(4) for j in range(i, 4))
print(sp.simplify(h2))                    # ∑ x_i² + ∑_{i<j} x_i x_j

# Schur s_(2,1) for x1, x2, x3
# From SSYT of shape (2,1) with entries in {1, 2, 3}:
# (1, 1 | 2), (1, 1 | 3), (1, 2 | 2), (1, 2 | 3), (1, 3 | 2), (1, 3 | 3),
# (2, 2 | 3), (2, 3 | 3) — sum to s_(2,1)(x1, x2, x3)
# Compute directly via sympy or by enumeration
s_21 = (x[0]**2 * x[1] + x[0]**2 * x[2] + x[0]*x[1]**2 +
        2*x[0]*x[1]*x[2] + x[0]*x[2]**2 +
        x[1]**2*x[2] + x[1]*x[2]**2)
print(sp.expand(s_21))
```

## Applied

- **Quantum integrable systems** — quantum spin chains' eigenvectors
  expanded in Schur / Macdonald polynomials.
- **Random matrix theory** — joint eigenvalue density for circular
  unitary ensembles is a symmetric function.
- **Combinatorial enumeration** — many counting problems unify
  through symmetric functions.
- **Algebraic geometry — Schubert calculus** on Grassmannians:
  intersection numbers via Schur products.
- **Algebraic combinatorics in CS** — algorithmic Schubert
  calculus, GIT quotients in vision/geometry.
