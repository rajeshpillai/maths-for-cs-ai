# The Fundamental Group

## Mental

Pick a basepoint $x_0 \in X$. A **loop** is a continuous map
$\gamma : [0, 1] \to X$ with $\gamma(0) = \gamma(1) = x_0$.

Two loops are **homotopic** if one can be continuously deformed into
the other (keeping the basepoint fixed).

The set of loop classes, with concatenation as group operation, is
the **fundamental group** $\pi_1(X, x_0)$.

## Examples

| Space | $\pi_1$ |
|---|---|
| $\mathbb{R}^n$ | trivial $\{e\}$ |
| Disk | trivial |
| Circle $S^1$ | $\mathbb{Z}$ — winding number |
| Sphere $S^2$ | trivial — every loop contracts |
| Torus $T^2$ | $\mathbb{Z} \times \mathbb{Z}$ — two loops |
| Figure-eight | $F_2$, free group on 2 generators |
| $\mathbb{RP}^2$ | $\mathbb{Z}/2$ |
| Klein bottle | $\langle a, b \mid abab^{-1} = e \rangle$ |

## Why winding number for $S^1$?

A loop on a circle wraps around an integer number of times. The
winding number is a homotopy invariant: $\pi_1(S^1) \cong \mathbb{Z}$,
generated by "wind once around."

This is why: when you walk through a doorframe wearing a wristwatch,
the loop made by your wrist either does or doesn't link with the
doorframe — and "how many times" is a count, not a magnitude.

## Simply connected

A space is **simply connected** if it's connected and $\pi_1 = \{e\}$.
The convex region, sphere, $\mathbb{R}^n$ are simply connected.

$S^1$, torus, donut surface are NOT simply connected — they have
"holes" that loops can wrap around.

## Symbolic

**Functoriality**: a continuous map $f : X \to Y$ induces a group
homomorphism $f_* : \pi_1(X, x_0) \to \pi_1(Y, f(x_0))$. Homeomorphic
spaces have isomorphic fundamental groups; non-isomorphic
fundamental groups prove non-homeomorphism.

**Van Kampen's theorem**: compute $\pi_1$ of $X = U \cup V$ from
$\pi_1(U), \pi_1(V), \pi_1(U \cap V)$ as an amalgamated free product.
The main calculation tool.

**Covering spaces**: space $\tilde X \to X$ where each point of $X$
has a neighbourhood whose preimage is a disjoint union of copies of
itself. Universal cover is simply connected; deck transformations
form the fundamental group.

## Computational

```python
# Loops and winding number around a point in C^*
import numpy as np

def winding_number(loop):
    """Estimate winding number of a closed planar loop around the origin."""
    angles = np.unwrap(np.angle([complex(*p) for p in loop]))
    return int(round((angles[-1] - angles[0]) / (2 * np.pi)))

# Loop wrapping origin once
t = np.linspace(0, 2*np.pi, 100)
loop = list(zip(np.cos(t), np.sin(t)))
print(winding_number(loop))               # 1

# Loop wrapping twice
loop2 = list(zip(np.cos(2*t), np.sin(2*t)))
print(winding_number(loop2))              # 2

# Loop not enclosing origin
loop3 = list(zip(2 + 0.5*np.cos(t), 0.5*np.sin(t)))
print(winding_number(loop3))              # 0
```

## Applied

- **Path planning around obstacles** — distinct homotopy classes of
  paths reach the same goal differently. Robotics motion planners
  pick best class via discrete representatives.
- **Knot theory** — knots are embeddings $S^1 \hookrightarrow S^3$;
  knot complements have complicated $\pi_1$ that distinguishes
  knots.
- **Loop quantum gravity** — quantum geometry built from spin
  networks; topology of physical configurations matters.
- **Topological materials** — materials whose electronic states have
  non-trivial topology (topological insulators, fractional Hall
  effect).
- **Computer graphics — homotopy continuation** — solve nonlinear
  equations by deforming from an easy system to the hard one.
