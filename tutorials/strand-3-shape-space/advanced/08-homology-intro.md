# Simplicial Homology

## Mental

The **fundamental group** captures 1-dimensional holes. To capture
holes of higher dimension, use **homology**.

A **simplicial complex** is built from points (0-simplices), edges
(1-simplices), triangles (2-simplices), tetrahedra (3-simplices), etc.

For each dimension $k$, define:

- **$C_k$**: free abelian group on $k$-simplices.
- **Boundary map** $\partial_k : C_k \to C_{k-1}$ — sends each
  simplex to its boundary with signs.
- $\partial_{k-1} \partial_k = 0$: "boundary of a boundary is zero."

The **$k$-th homology**:

$$
H_k = \ker \partial_k / \mathrm{im}\, \partial_{k+1}.
$$

$\dim H_k$ = "number of $k$-dimensional holes."

## Worked example: triangle

Three vertices $\{v_0, v_1, v_2\}$, three edges $\{e_{01}, e_{12}, e_{02}\}$.
*Hollow* triangle — no 2-simplex.

$C_1 = \mathbb{Z}^3$ generated by edges.
$C_0 = \mathbb{Z}^3$ generated by vertices.

$\partial_1(e_{01}) = v_1 - v_0$, etc.

$\ker \partial_1$: $a e_{01} + b e_{12} + c e_{02}$ with
$a(v_1 - v_0) + b(v_2 - v_1) + c(v_2 - v_0) = 0$. Working out gives
$a = b = -c$, so $\ker = \mathbb{Z}$.

$\mathrm{im}\, \partial_2 = 0$ (no 2-simplices).

$H_1 = \mathbb{Z}/0 = \mathbb{Z}$ — *one* 1-dim hole. ✓

If we **fill in** the triangle with a 2-simplex $f$, then
$\partial_2(f) = e_{01} + e_{12} - e_{02}$. The kernel of $\partial_1$
is now in the image, so $H_1 = 0$ — no holes.

## Betti numbers

$\beta_k = \dim H_k$ (rank, using rational or real coefficients).

| Space | $\beta_0$ | $\beta_1$ | $\beta_2$ |
|---|---|---|---|
| Point | 1 | 0 | 0 |
| Circle | 1 | 1 | 0 |
| Sphere $S^2$ | 1 | 0 | 1 |
| Torus | 1 | 2 | 1 |
| Klein bottle | 1 | 1 | 0 (over $\mathbb{Q}$) |

**Euler characteristic**: $\chi = \sum_k (-1)^k \beta_k$. For a
torus: $1 - 2 + 1 = 0$. ✓ Consistent with Lesson 06.

## Symbolic

**Persistent homology** (Strand 2 Advanced Lesson 09): track Betti
numbers as a parameter (e.g., scale) varies. Features that **persist**
across scales are signal; transient ones are noise. The *barcode* is
the canonical visual output.

**Reduced homology**: $\tilde H_0 = H_0 / \mathbb{Z}$ — kills the
"trivial" component.

**Cohomology** $H^k$: dual theory using $\mathrm{Hom}(C_k, R)$. For
nice spaces, $H_k$ and $H^k$ are isomorphic; in general they differ
by torsion (universal coefficient theorem).

## Computational

```python
import numpy as np

# Boundary matrix of a triangle (V=3, E=3, F=0 hollow)
# Edges: e_01, e_12, e_02
# d_1 maps edges to vertices: e_01 -> v_1 - v_0, etc.
d1 = np.array([
    [-1,  0, -1],   # v_0 contributes
    [ 1, -1,  0],   # v_1
    [ 0,  1,  1],   # v_2
])

print(np.linalg.matrix_rank(d1))           # rank 2
# kernel of d_1 has dim 3 - 2 = 1 — H_1 dimension since image of d_2 is empty

# With filled triangle: d_2 sends face -> e_01 + e_12 - e_02
d2 = np.array([
    [1, 1, -1],
]).T

# Image of d_2 is dim 1, so H_1 = ker(d_1)/im(d_2) = Z/Z = 0
# Compute via ranks: dim(ker d_1) = 1, dim(im d_2) = 1 → H_1 has rank 0

# Compute Betti numbers from boundary matrices
def betti_number(d_kp1, d_k, ambient_dim):
    rank_dk = np.linalg.matrix_rank(d_k) if d_k is not None else 0
    rank_dkp1 = np.linalg.matrix_rank(d_kp1) if d_kp1 is not None else 0
    return ambient_dim - rank_dk - rank_dkp1

# beta_1 of hollow triangle
print(betti_number(None, d1, 3))            # 1
# beta_1 of filled triangle
print(betti_number(d2, d1, 3))              # 0
```

## Applied

- **Topological data analysis (TDA)** — persistent homology
  identifies robust topological features in point clouds. Used for
  cancer-cell shape, financial-market regime changes, sensor-network
  coverage.
- **Manifold learning** — homology distinguishes whether high-dim
  data lies on a low-dim manifold and what its topology is.
- **3D mesh repair** — detect handles or boundary holes in scanned
  meshes via discrete homology.
- **Quantum field theory** — anomalies and topological invariants in
  gauge theories use cohomology.
- **Sensor coverage** — homology of nerve complexes detects coverage
  holes in sensor networks (Robert Ghrist's work).
