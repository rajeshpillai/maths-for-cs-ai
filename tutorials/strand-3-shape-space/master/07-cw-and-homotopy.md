# CW Complexes and Homotopy

## Explain Like I Am 7

Think of building a Lego model: start with a few studs (dots), snap
in some long bricks (lines), then glue on flat plates (filled-in
squares), then maybe stack on chunky 3D blocks.  A **CW complex** is
exactly that — a shape built up dot-by-line-by-tile-by-block, in
careful steps.  And **homotopy** is the rule for deciding when two
finished Lego shapes can be slowly squished into each other without
breaking, even if they look totally different from the outside.

## Mental

A **CW complex** is a topological space built by inductively gluing
**cells**:

- Start with a discrete set $X^0$ — the **0-skeleton**.
- $X^n$ obtained from $X^{n-1}$ by attaching $n$-cells $D^n$ via
  attaching maps $\partial D^n = S^{n-1} \to X^{n-1}$.

Examples:

- $S^n$: one 0-cell, one $n$-cell.
- $\mathbb{CP}^n$: one cell in each even dim 0, 2, 4, ..., $2n$.
- Torus $T^2$: one 0-cell, two 1-cells, one 2-cell.

CW complexes are *combinatorially* tractable: cellular homology
computes everything from attaching maps.

## Cellular homology

For a CW complex $X$:

$$
C_n(X) = \mathbb Z^{(n\text{-cells})}.
$$

Boundary $\partial_n : C_n \to C_{n-1}$ given by attaching maps'
*degrees*. Then $H_n(X) = \ker \partial_n / \mathrm{im}\, \partial_{n+1}$.

For $S^2$: $C_0 = \mathbb Z, C_2 = \mathbb Z$, others zero. So
$H_0 = H_2 = \mathbb Z$, $H_1 = 0$. Matches Strand 3 Advanced
Lesson 08.

## Homotopy equivalence

Two spaces are **homotopy equivalent** if there are maps $f : X \to Y$,
$g : Y \to X$ with $g \circ f \simeq \mathrm{id}_X$ and
$f \circ g \simeq \mathrm{id}_Y$ (where $\simeq$ means
homotopic).

Homotopy invariants: $\pi_n, H_n$, $\chi$, etc.

Examples:

- $\mathbb R^n$ contractible (homotopy equivalent to point).
- $S^1 \simeq S^1$ via degree-$\pm 1$ self maps.
- A coffee mug $\simeq$ a donut (genus 1).

## Higher homotopy groups

$\pi_n(X)$: homotopy classes of maps $S^n \to X$.

| Space | $\pi_1$ | $\pi_2$ | $\pi_3$ |
|---|---|---|---|
| $S^1$ | $\mathbb Z$ | 0 | 0 |
| $S^2$ | 0 | $\mathbb Z$ | $\mathbb Z$ (Hopf!) |
| $S^3$ | 0 | 0 | $\mathbb Z$ |

$\pi_3(S^2) = \mathbb Z$ generated by the **Hopf fibration** —
striking: a non-trivial map $S^3 \to S^2$ even though "topologically"
$S^3$ has higher dim than $S^2$.

## Symbolic

**Whitehead's theorem**: a map of CW complexes inducing isomorphisms
on all $\pi_n$ is a homotopy equivalence.

**Eilenberg-MacLane space** $K(\pi, n)$: space with $\pi_n = \pi$ and
$\pi_k = 0$ otherwise. Universal — represents singular cohomology
$[X, K(\pi, n)] = H^n(X; \pi)$.

**Postnikov tower**: any space can be approximated by Eilenberg-
MacLane spaces fibred together.

**Stable homotopy theory**: study $\pi_n^s = \mathrm{colim}_k \pi_{n+k}(S^k)$.
Computed via Adams spectral sequence; mostly a frontier.

# T^2 CW structure: 1 0-cell, 2 1-cells (a, b), 1 2-cell (gluing word aba⁻¹b⁻¹)

# Boundary ∂_1 of 1-cell ending at the 0-cell: ∂_1 a = (-1+1) v = 0
# Same for b. So ∂_1 = 0.

# Boundary ∂_2 of 2-cell with gluing word aba⁻¹b⁻¹:
# ∂_2 = a + b - a - b = 0
import numpy as np

# H_0 = ker d_0 / im d_1 = Z (since d_0 ≡ 0 trivially, d_1 image is 0)
# H_1 = ker d_1 / im d_2 = Z² / 0 = Z²
# H_2 = ker d_2 = Z (no d_3)

print("Torus homology: H_0 = Z, H_1 = Z², H_2 = Z")

## Applied

- **Topological data analysis** — persistent CW complexes; cellular
  computation of persistence.
- **Computer graphics** — meshes are 2D CW complexes; cell-complex
  surgery for topology editing.
- **String topology** (Chas-Sullivan) — operations on loop spaces of
  manifolds.
- **Quantum computation** — Stevenson-Kirby-Siebenmann moves on
  CW complexes generate equivalences underlying topological-quantum
  protocols.
- **Persistent cohomology** — uses cellular cohomology; supports
  TDA of streaming data.
