# Algebraic Topology Deeper

## Mental

Algebraic topology turns topological problems into algebraic ones via
**functors** $X \mapsto H_*(X), \pi_*(X), \ldots$.

Key constructions beyond Lessons 06-07:

- **Cup product**: $H^p \otimes H^q \to H^{p+q}$. Makes
  $H^*(X; R)$ a graded ring.
- **Poincaré duality**: for closed orientable $n$-manifold $M$,
  $H^k(M) \cong H_{n-k}(M)$.
- **Lefschetz fixed-point theorem**: count fixed points of a map via
  trace in cohomology.

## Spectral sequences

**Serre spectral sequence**: for a fibration $F \to E \to B$,
$E_2^{p, q} = H^p(B; H^q(F))$ converges to $H^{p+q}(E)$.

Used to compute homology of total spaces, spheres, classifying spaces.

**Adams spectral sequence**: $E_2 = \mathrm{Ext}^{*, *}_{\mathcal A}(\mathbb F_2, \mathbb F_2)$
converges to stable homotopy of spheres mod 2.

## Cobordism and TQFTs

Two manifolds are **cobordant** if their disjoint union is the
boundary of one higher-dim manifold. Cobordism classes form a ring
under disjoint union and Cartesian product.

**Thom spectrum** $MO$: stable homotopy version of cobordism;
unstable cobordism rings are $MO_*$.

**TQFT** (Atiyah, 1989): a symmetric monoidal functor
$\mathrm{Cob}_n \to \mathrm{Vec}_\mathbb C$. Examples: Chern-
Simons, Jones polynomial, Khovanov homology, Reshetikhin-Turaev.

## Equivariant and stable homotopy

**Equivariant**: account for a group $G$ acting; $\pi_n^G(X)$.

**Stable**: stabilise by suspension $\Sigma X = S^1 \wedge X$. Stable
homotopy category has very different — and better-behaved — structure.

## Symbolic

**Hurewicz theorem**: for $n \ge 2$ and $\pi_k(X) = 0$ for $k < n$,
the map $\pi_n(X) \to H_n(X)$ is an isomorphism. Bridges
homotopy and homology.

**Atiyah-Singer index theorem** (1963): for an elliptic operator $D$
on a compact manifold, the analytical index (kernel - cokernel)
equals a topological index built from characteristic classes. Won
Atiyah and Singer the Abel Prize.

**Gauge theory and 4-manifold topology** — Donaldson, Seiberg-Witten
invariants distinguish exotic 4-manifold smooth structures.

**Persistent cohomology / persistent homotopy** — emerging frontier
of computational topology.

## Computational

```python
import numpy as np

# Cup product on the torus T² cohomology
# H¹(T²) = Z² generated by [a*], [b*] (dual to 1-cells a, b)
# Cup product: [a*] cup [b*] = [a*∧b*] generates H²(T²) = Z

# Lefschetz fixed-point via traces:
# For map f: T² → T² of degree d, Lefschetz number = trace on H_0 - trace on H_1 + trace on H_2
# = 1 - tr(f_1) + d
# If f = identity: Lefschetz = 1 - 2 + 1 = 0. Indeed T² has identity with no isolated fixed points (every point fixed)
# If f a "rotation": Lefschetz = 1 - 0 + 1 = 2 (matching 2 fixed points of generic rotation in plane sense)

# Compute Euler char of CP^n (= n+1 from cells in even dims 0, 2, 4, ..., 2n)
def chi_cpn(n):
    return n + 1
print([chi_cpn(n) for n in range(5)])    # [1, 2, 3, 4, 5]

# Cobordism: closed 1-manifolds (circles only) all bound disks
# So Ω_1 (unoriented cobordism in dim 1) = 0
# Ω_0 = Z/2 (count parity of points)
print("Ω_0 = Z/2, Ω_1 = 0, ...")
```

## Applied

- **Topological data analysis** — persistent cohomology with cup
  products gives ring-valued descriptors.
- **Topological field theories** — Witten's TQFT gave Jones
  polynomial, related knot invariants.
- **Distributed systems / consensus protocols** — topological
  obstructions (Herlihy-Shavit) to consensus in asynchronous
  models.
- **String theory** — anomaly cancellation requires specific
  cohomology vanishings (Green-Schwarz, M-theory).
- **AI / Geometric deep learning** — equivariant networks use
  topological invariants for shape descriptors.
